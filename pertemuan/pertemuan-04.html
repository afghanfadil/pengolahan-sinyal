01. Sifat sistem waktu-diskrit

Pertemuan 4

Kriteria analisis

Linear: memenuhi superposisi. Invarian waktu: pergeseran input memberi pergeseran output identik. Kausal: tidak memerlukan masukan masa depan. Tanpa memori: hanya bergantung pada x[n]. BIBO stabil: masukan terbatas selalu menghasilkan keluaran terbatas.

T{ax₁ + bx₂} = aT{x₁} + bT{x₂}
Sistem y[n] = x[n]² tetap kausal dan invarian waktu, tetapi tidak linear.

Pertemuan 4

Model dinamik

Output saat ini merupakan gabungan input saat ini dan state output sebelumnya. Untuk kondisi diam y[−1] = 0, sistem dengan |a| < 1 memiliki respons impuls yang menurun.

03. Sistem LTI dan respons impuls

Pertemuan 4

Linear Time-Invariant (LTI)

Respons impuls h[n] menggambarkan keluaran sistem ketika masukan berupa δ[n], dengan kondisi awal nol. Setiap deret masukan dapat ditulis sebagai gabungan impuls yang digeser; lewat linearitas dan invariansi waktu diperoleh operasi konvolusi.

x[n] = Σₖ x[k] δ[n−k]
y[n] = Σₖ x[k] h[n−k]
Untuk sistem LTI, kausal jika h[n]=0 pada n < 0. Stabil BIBO jika Σₙ |h[n]| < ∞.

Contoh filter dua tap

Rata-rata bergerak dua sampel menyaring perubahan cepat:

h[n] = ½δ[n] + ½δ[n−1]

Dengan x = [2, 4, 8] untuk n=0,1,2, hasil konvolusi adalah y = [1, 3, 6, 4] pada n=0,1,2,3.

Konvolusi & persamaan beda (pertemuan 4)

x = [1 2 1]; h = [1 1];
y = conv(x,h); disp(y);  % [1 3 3 1]
n = 0:11;
xstep = ones(size(n));
yrec = filter(1,[1 -0.5],xstep);
stem(n,yrec,'filled'); grid on;
xlabel('n'); ylabel('y[n]');
title('y[n] = 0.5 y[n-1] + u[n]');
